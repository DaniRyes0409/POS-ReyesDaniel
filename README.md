# POS-ReyesDaniel

## Descripción general
Sistema de gestión integral para cafetería con Punto de Venta (POS) y panel de administración, desarrollado de forma nativa para escritorio. Permite gestionar ventas, productos, categorías y usuarios, además de generar tickets y visualizar reportes métricos de ingresos y egresos.

## Tecnologías utilizadas
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Backend / Escritorio**: Node.js, Electron
- **Base de Datos**: SQLite (sql.js) / MySQL (en migración)

## Instrucciones de instalación y ejecución

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/DaniRyes0409/POS-ReyesDaniel.git
   cd POS-ReyesDaniel
   ```

2. **Instalar las dependencias:**
   ```bash
   npm install
   ```

3. **Ejecutar la aplicación:**
   ```bash
   npm start
   ```
